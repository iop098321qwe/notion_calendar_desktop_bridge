Notion Calendar → Desktop¶

Open Notion task links from Notion Calendar in Notion Desktop rather than opening another browser tab. Both calendar.notion.com and calendar.notion.so are supported.

Install¶

Requires a Chromium-based browser supporting MAIN-world content scripts (Chromium 111 or newer), plus Notion Desktop registered for notion:// URLs.

  1. Open brave://extensions (or chrome://extensions).
  2. Enable Developer mode and choose Load unpacked.
  3. Select this checkout's extension/ directory.
  4. Reload Notion Calendar and click a linked Notion task.
  5. Approve the browser's external-application prompt when requested.

To check the desktop protocol handler on Linux:

xdg-mime query default x-scheme-handler/notion

How it works¶

  • extension/direct.js intercepts Calendar task clicks at document start, during the original user gesture, and hands off in the existing tab.
  • extension/links.mjs validates supported HTTPS Notion task URLs and converts their page IDs into desktop URLs.
  • extension/background.mjs handles otherwise unhandled Calendar navigations.
  • extension/launch.html and launch.mjs provide desktop-launch and explicit web-fallback links when the direct route cannot be used.

The worker remembers source tab IDs in session storage across suspension, not task URLs. Independently opened Notion tabs are left unchanged. The extension uses only the scoped Notion hosts declared in its manifest.

Tests¶

Requires Node.js with the built-in test runner; no npm dependencies are needed to execute the tests.

npm test

The suite covers URL validation, direct handoff, user activation, converter parity, source-tab scoping, navigation races, worker restart, and fallback. Browser APIs are mocked; authenticated Calendar behavior and desktop protocol prompts still need a manual browser check.

Update and troubleshoot¶

After changing files, use the extension's Reload button and reload Calendar. Unpacked extensions do not update automatically from GitHub. If handoff is blocked, use the launch page's desktop button and check the OS protocol handler. Remove the extension in browser settings to uninstall.

Repository maintenance¶

This repository maintains the extension previously stored in Chezmoi at dot_local/share/notion-calendar-desktop-bridge. The manifest version is unchanged; releases are cut manually.

Chezmoi's existing deployment copies and browser loading helper are retained until a separate deployment cutover. They still target ~/.local/share/notion-calendar-desktop-bridge. Loading this checkout instead may change its unpacked extension ID; disable the old copy to avoid duplicate handlers.
